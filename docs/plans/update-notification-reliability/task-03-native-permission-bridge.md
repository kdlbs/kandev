# Task 03: Move Native Notification Permission to a User Gesture

## Acceptance

- The native bridge accepts semantic session, failure, and update occurrences
  but rejects the retired `session.waiting_for_input` prefix.
- Background delivery never requests permission; narrow origin-checked commands
  query permission and request it only from a user action.
- Rust permissions/schemas and the typed frontend client expose the same command
  contract, with tests for denied, duplicate, and failed-display behavior.
