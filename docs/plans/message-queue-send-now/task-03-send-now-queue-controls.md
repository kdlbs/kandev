# Task 03: Add Send Now queue controls

## Intent

Expose the new action through the shared queue API/hook and add accessible row
and header controls that work through hover/focus on desktop and direct touch on
coarse-pointer layouts.

## Acceptance

1. The API and hook send the exact `entry`/`all` payloads, map stable errors,
   and refetch authoritative queue state after every result.
2. Every row exposes hover/focus **Send Now** on fine pointers and an always-
   visible 44px touch control on coarse pointers; header **Send Now** appears
   immediately before **Clear all** and sends the whole snapshot.
3. Duplicate actions are disabled during local loading or authoritative
   cancellation, all new copy is localized, and the narrow header wraps without
   adding another scroll owner or horizontal overflow.
