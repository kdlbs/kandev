# Task 02: Enable Resizing in Editable Plan View

## Summary

Enable TipTap's native table-column drag behavior in the live Plan panel on
desktop fine-pointer layouts. Keep widths ephemeral and source-preserving, and
remove the resize plugin when the viewport or pointer capability becomes
ineligible.

## In scope

- Configure live Plan `Table` extensions with responsive resizing, a 64-pixel
  minimum, and internal boundaries only.
- Recreate the editor from parent draft Markdown when resize capability changes.
- Add Plan-scoped wrapper, handle, cursor, and overflow CSS.
- Add focused desktop and Mobile Chrome Plan table E2E coverage.

## Out of scope

- Changing read-only revision previews or comparison dialogs.
- Persisting ProseMirror `colwidth` attributes.
- Replacing TipTap's table plugin with a custom resize engine.
- Adding Plan table authoring, row, or column management commands.

## Acceptance

- A desktop Plan table supports internal-boundary drag, enforces the 64-pixel
  minimum, and remains contained by its local table wrapper.
- Width-only editor state never changes persisted plan Markdown and clears after
  reload or capability loss without losing current draft text.
- Mobile and coarse-pointer Plan layouts expose no resize affordance, keep table
  content readable, and cause no document horizontal overflow.

  styles and selectors must remain Plan-scoped.
