# Preserve tab renames during composition

## Outcome and scope

Repair `AC-UI-EDIT-FOCUS-001.4` in the existing shared input. The parent
diagnostic reproduced two premature `session.rename` writes (composing Enter
and legacy 229 Enter) and a composing Escape cancellation on main
`995e79dabe7bc743671d9a7a0fc45e9e1dd1999f`. An ordinary Enter control passed.
The root cause is unconditional Enter/Escape resolution in `TabRenameInput`.
Neighboring title inputs already implement the intended local guard.

The user explicitly authorized this package and TDD implementation in the
same turn. No material behavior choice is unresolved. Preserve Unicode
code-point insertion bounds, terminal defaults, blur behavior, completion
counts, and target isolation. No framework, lifecycle, API, schema, dependency,
layout, or product-copy change is needed.

## Order and ownership

One sequential [work order](task-01-guard-composition.md) owns the input,
focused tests, and this delivery record. Write permanent regression tests,
capture causal RED, apply the minimum local guard, then capture GREEN and
task-defined checks. No delegation or extra platform tasks are authorized.

## Responsive and evidence boundaries

Desktop session and terminal menus retain their existing inline input.
Preview session tabs share it. Tablet `SessionTabletLayout` mounts
`TaskRightPanel`, whose ordinary terminal rename also shares it. Phone
`SessionMobileLayout` uses the native Sessions picker and
`MobileTerminalPane`; neither exposes this input. Do not invent a phone rename
action. The existing `mobile-session-unicode-name.spec.ts` covers phone
selection/value compatibility: its source and all phone sources are unchanged
by this repair, which only adds a keyboard early return to a non-phone input.
Run that existing scenario against the final assets. No layout, touch,
navigation, scrolling, or viewport branch changes are proposed.

Browser composition events are dispatched, not generated by a physical OS IME.
Unit tests own keyboard flags, default behavior, propagation, and at-most-once
resolution. The actual session input/hook/API/store suite mocks only WS
transport. Browser checks own native entry-point wiring and persistence for
session and desktop/tablet terminal consumers.

## Documentation and risks

Public docs assessment: coordination documents the existing Rename action and
name limit, and WebSocket docs list the existing actions. This repair restores
composition behavior without changing those instructions, terminology, or
protocols; only the existing internal requirement/design need refinement.
No ADR is needed for the established local rule. Physical-device IME behavior
remains outside automated evidence.
