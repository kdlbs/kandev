Merge-group cancellation remains prohibited.

## E2E findings

PR 4352's 14 normal test steps took 26.2–34.3 minutes. The current duration planner already balances this cohort reasonably.
The artifact reports 3,924 first-attempt passes, four passes after retry, and 47 skips across 3,975 declarations.
The sampled normal and container projects executed 3,928 tests. This does not establish coverage of every configured opt-in project.
Do not remove retries or mobile coverage to claim improvement.

Container shard 1 had a 24-second test step, with only about two seconds inside its recorded Playwright invocation.
Its plan predicted 720 seconds for `kubernetes-docker-workloads.spec.ts`.
All four declarations skip without `KANDEV_E2E_FULL_WORKER_IMAGE`, which the ordinary workflow does not supply.
Container shard 5 took 15.3 minutes. Changing estimates or fixture costs needs context-aware proof before adopting a new plan.
Do not silently drop the skipped declarations or describe them as executed Docker acceptance coverage.

Shared fixtures perform repeated integration deletes, mock resets, settings resets, and Git origin restoration/fetches.
`testPage` and `integrationCleanup` in `e2e/fixtures/test-base.ts` are concrete profiling targets.
These operations protect isolation; source inspection does not prove any can be removed or parallelized safely.

## Avoidable selection

[PR 4349](https://github.com/kdlbs/kandev/pull/4349) changes only three Go unit-test files:

- `apps/backend/internal/orchestrator/executor/executor_credentials_test.go`
- `apps/backend/internal/orchestrator/executor/executor_host_gh_bridge_test.go`
- `apps/backend/internal/orchestrator/executor/executor_host_gh_fake_test.go`

The E2E workflow currently treats every non-documentation backend path as relevant.
A verified Go-test-only exemption can avoid the application's build and E2E fan-out for such PR revisions.
The approximately 550 runner-minute saving uses other full E2E runs as a scale estimate, not a measured saving on PR 4349.
Keep backend unit/static coverage and normal main/merge-group verification.

## Implementation evidence (October 9)

The baseline full frontend suite passed locally with 2,757 files, 24,569 passed
tests, four skipped tests, and zero failures. Vitest report elapsed time was
2,627.355 seconds. Child-process localhost connection errors appeared in the
log, but the process exited zero and the complete report records success.
Raw output is `/tmp/kandev-ci-implementation/baseline-full.json` and its sibling
log. This is a local sample, not a new hosted performance result.

The first full candidate selected every file and assertion but had one failure.
Its 1,643.766-second result is a failed attempt, not an accepted speedup.
`clipboard-attachments.test.ts` spies on `DOMParser`, which the initial heuristic
missed. Its assignment was corrected from Node to browser without changing the
test. The corrected complete candidate passed: 2,757 files, 24,569 passed tests,
four skipped tests, and exact identity/outcome parity. Report elapsed was
1,641.299 seconds (27m21s), 37.5% below the 2,627.355-second baseline.
This is one local full pair, not a hosted median; the 40% target was not met.
The experiment retains the configured local worker budget, production-environment
pin, isolation, and all identities.
The reviewed candidate assignments are 420 Node, 867 English-browser, and 1,470
full-locale files. Workspace UI dependencies were separately inspected: the
shared UI package does not load or switch the application's locale catalogs.
Unknown dynamic, locale-sensitive, and larger indirect dependency cases remain
on the original setup.

Validation uses one complete before/after pair for coverage and three stratified
setup pairs for cost attribution. The 96-file sample contains 48 newly migrated
Node files and 48 newly migrated browser files, distributed across directories
and local dependency sizes. Existing fast-project files are excluded from that
sample to avoid inflating the baseline. The sample replaced the misclassified
clipboard file with another Node helper from the same directory before running.
All six runs passed the same 96 files and 925 tests with exact identity/outcome
parity. Median command elapsed fell from 60.608s to 20.400s (66.3%). These
sample medians remain separate from full-suite and hosted claims.

Workflow checks and Actionlint pass. The changed-workflow Zizmor comparison has
one unchanged Windows CMD finding; the full-repository scan has pre-existing
findings elsewhere. The active main ruleset was read and its three test-check
names are preserved. The actual PR 4349 commit range selects the independent-Go-
tests exemption. No new GitHub benchmark runs or runner purchases were made.

See [E2E fixture cost follow-up](e2e-cost-follow-up.md) for the 20-artifact hosted
fixture analysis and explicitly unmeasured per-operation costs.

### Scope of the Go-test-only saving

A read-only scan of the 50 most recently updated open/merged PRs found two
path-only candidates: #4349 and #3955. Eleven file lists exceeded the 100-file
