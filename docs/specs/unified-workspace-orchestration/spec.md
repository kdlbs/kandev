# Unified workspace orchestration

Status: implemented and verified in the isolated preview.

An optional chief manages an existing Kanban workspace. Assignment must not create a second workspace or delivery workflow. Conversations belong to the workspace and are hidden from delivery columns. Existing tasks, workflows, execution profiles, repositories and sessions remain canonical. Personal coordination may route work tasks, but execution remains pinned to the selected account. Legacy Office URLs and data remain accessible.

Acceptance: configure a chief on an existing board; converse in the shared shell; create and manage tasks on its existing workflow; preserve account placement and single execution ownership; receive concise results. Workspace settings own persona setup after Kanban onboarding. No separate Office onboarding or product switch in the primary flow.
