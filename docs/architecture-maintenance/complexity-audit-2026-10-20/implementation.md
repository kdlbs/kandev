## Validation

The sidebar regression first failed with `expected true to be false`, establishing the incorrect preset projection before the fix.

- **Backend:** `go test -tags fts5 -p 2` across all 48 touched/new packages. The first batch passed 47 packages; the SQLite package reached the default ten-minute limit without an assertion failure. Its isolated `-timeout 20m` rerun passed in 581.627 seconds. The Office service suite passed again after the final admission/session-validation extraction.
- **Web tests:** the broad selected run covered store composition, slices, hydration, settings, provider accumulators, API clients, and utilities, with 1,356 tests passing. Its eight serializer failures exposed an overly strict mutation requirement in the new adapter. After separating read and resize contracts, the complete focused layout run passed all 114 tests in 13 files; the other selected suites were unchanged.
- **Types:** `NODE_OPTIONS=--max-old-space-size=6144 pnpm exec tsc --noEmit --pretty false` passed after the final adapter change.
- **Production build:** `pnpm run build:vite` passed, with bundle-size and dynamic-import warnings.
- **Static checks:** changed-package Go lint, with a final focused Office rerun reporting zero issues; changed-file ESLint, gofmt, Prettier, architecture lint, documentation catalog validation, i18n new-code/coverage checks, and public-copy checks passed.
- **Merge compatibility:** after rebasing onto current `main`, preserved the image-preview defaults imports alongside the typed UI slice. The combined UI state passed 275 tests in 26 files, the TypeScript check passed again, and both automatically merged Go packages (`backendapp` and `orchestrator`) passed compilation checks with `-run '^$'`.
- **Scope:** browser E2E and the full backend race suite were not run. The sidebar correction is covered by the preset integration regression test, including legacy-sidebar preservation.
